# NavRail

Desktop left rail: menu, Chats / Calls / Stories, then Settings and your avatar at the bottom.

- `rail-width` 68px on `surface-sidebar`, with a `divider` line on its right.
- The active item gets a `surface-selected` pill. Unread totals show as an `alert` badge.
- Calls and Stories open a ComingSoon panel. Below 600px the rail becomes the TabBar.
