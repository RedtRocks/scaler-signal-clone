# GetStartedCard

The "Get started" carousel under a short chat list (Figma Output 1): 173×185 cards with 12px radius and a 0 0 32px shadow.

- The art panel is 131px of `ios-illustration-bg` #f0f3fb holding the Figma illustration (in the Illustrations asset group). Below it sits a #f6f6f6 pill with a 16px semibold label in `ios-primary-blue`.
- A grey 22px dismiss disc sits top-right. Cards scroll horizontally with 10px gaps.
- Wire them to New group, Invite friends (ComingSoon) and Appearance (theme settings). This also makes a good empty state for a freshly seeded account.
