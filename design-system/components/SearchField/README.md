# SearchField

Search field at the top of the conversation list.

- Desktop: 32px tall, `surface-field`, `radius-md`, 14px text.
- Phone (Figma): 38px tall, #e9e9e9 (`ios-field`), `radius-field` 10px, 18px text at −4% tracking, placeholder and icon #858585.
- Filter conversations and contacts as the user types. Ctrl/⌘+F focuses it on desktop.
