# ChatHeader

Top bar of the chat pane: avatar, name, optional subtitle, and call/search/more actions.

- Desktop: 56px tall, 32px avatar, 16px semibold name, then video, phone, search and more.
- Phone (Figma): back chevron, 38px avatar, 18px semibold name with the `verified` badge, then video and phone only (`compact`).
- The subtitle carries presence (`online`, `last seen 2h ago`), the disappearing timer, or a member count.
- Groups drop the voice-call button. Tapping the name opens the contact or group details.
