# Avatar

Circular avatar: a photo, initials on Signal's lavender disc, the default group glyph, or Note to Self.

- Figma defaults: initials `avatar-initials-ink` #3a39eb on `avatar-initials-bg` #e3e4fd; groups `avatar-group-ink` #a8261c on `avatar-group-bg` #f0d9d7.
- Sizes: desktop rows 48, header 32, group sender 28; phone (Figma) rows 58, header and member rows 38, contact details 96.
- `online` adds a `success` dot (mocked presence).
