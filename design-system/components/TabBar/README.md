# TabBar

Phone bottom tab bar from the Figma: Chats and Stories, 57px tall above the home indicator.

- Icons are the Figma `tab-chats` (filled bubble) and `tab-stories` glyphs at 28px. Labels are 11px medium at −3%.
- Active tab uses `ink` #1b1b1b. Inactive uses `ios-placeholder` #858585.
- Red `alert` count badges sit on the icon's top-right corner.
