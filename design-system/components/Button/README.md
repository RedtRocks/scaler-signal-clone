# Button

Pill buttons for dialogs and onboarding, and square icon buttons for headers and the composer.

- `primary` (ultramarine) for the one forward action per screen: Continue, Send code, Create group.
- `secondary` for Cancel. `destructive` for Delete or Remove member.
- Text links on phones use `ios-primary-blue` #3e67e2 (Figma 'Primary Blue').
- `icon` buttons need an `aria-label`. They have a 36px hit area.
