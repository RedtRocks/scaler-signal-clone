# SystemNotice

Centred grey line for timeline events: date separators, timer changes, members added or removed, safety-number notes.

- `ink-secondary`, 13px on desktop and 15px on phones, with an optional 16px icon (`disappearing` for timer changes).
- Use it for: "You created the group", "Julian Smith made you an admin.", "Maya set disappearing message time to 1 day.", and day dividers.
