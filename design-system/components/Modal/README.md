# Modal

Centred dialog on a scrim for New chat, Add contact, New group, member management and confirmations.

- `surface-raised`, `radius-lg` and `shadow-modal`, at most 400px wide.
- Actions sit bottom-right: secondary, then primary. Destructive confirmations use the destructive button.
- Esc and the close button dismiss it. Trap focus while it is open.
- On phones, use a full-screen sheet with the iOS nav bar (`ios-navbar`) instead.
