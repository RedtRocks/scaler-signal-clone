Icons exported vector-for-vector from the Figma file 'Signal | App Recreation (Community)', in their original Figma colours. The SignalUI `Icon` component carries the same geometry recoloured to `currentColor`. `receipt-read` and `receipt-read-outgoing` are the Figma read-receipt marks, for reference only: the `DeliveryStatus` component draws all four states. A few glyphs (contact, verified, sounds, permissions, muted) cut white knockout shapes, so place them on light grounds or use the component, which recolours the knockout to the surface. The Figma's Leave Group glyph does not export cleanly, so it is redrawn in the component and left out of this group.
